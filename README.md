# invoice-ops-agent

Agente autónomo que procesa facturas (PDF/imagen), extrae sus datos con un LLM con visión,
las concilia contra órdenes de compra y pagos en Postgres y decide si aprobarlas, enviarlas a
revisión humana o pedir más información, dejando cada decisión justificada y auditada.
